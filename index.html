💡 안드로이드 테스트 시 필독 주의사항

로컬 PC에서 안드로이드 폰으로 접속할 때 사설 IP(예: 192.168.x.x)로 접속하면 Web NFC 보안 정책(HTTPS 필수)에 의해 API가 차단됩니다.

권장 해결책 (2가지):
  1. Chrome DevTools Port Forwarding (추천): 안드로이드 폰과 PC를 USB로 연결 후, PC 크롬에서 chrome://inspect/#devices 접속 → 5173 포트포워딩 설정 → 폰 크롬에서 http://localhost:5173 접속 (보안 권한 즉시 통과)
  2. Vercel 배포: Vercel로 배포하여 생성된 https://... 도메인으로 접속
